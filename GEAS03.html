Questions Q12 – Q19 Trace Breakdown
🔴 MUST MEMORIZE Q12 Code Trace

Modulo Loop Total Calculator

Total = 0
FOR i = 1 to 4 DO:
  IF (i % 2 == 0) Total += (i * 2)
  ELSE Total += i

• $i=1$: Odd $\rightarrow$ $\text{Total} = 0 + 1 = 1$

• $i=2$: Even $\rightarrow$ $\text{Total} = 1 + (2 \times 2) = 5$

• $i=3$: Odd $\rightarrow$ $\text{Total} = 5 + 3 = 8$

• $i=4$: Even $\rightarrow$ $\text{Total} = 8 + (4 \times 2) = 16$

FINAL Total = 16
⚠️ TRAP DETECTOR Q13 Code Trace

C Post-Increment (`y++`) Evaluation

int x = 5, y = 2, z = 0;
if (x > 3 && y++) z = x * y;
printf("%d", z);

1. $x > 3$ evaluates to TRUE (5 > 3).

2. $y++$ returns original value 2 (TRUE), then increments $y \rightarrow 3$.

3. Execution inside IF: $z = x \times y = 5 \times 3 = 15$.

OUTPUT = 15
🟠 HIGH-YIELD Q14 Loop Counter

Integer Division Loop Count

int count = 0, value = 20;
while (value > 2) { value /= 2; count++; }

• Pass 1: $20 > 2 \rightarrow value = 10, count = 1$

• Pass 2: $10 > 2 \rightarrow value = 5, count = 2$

• Pass 3: $5 > 2 \rightarrow value = 2, count = 3$

• Pass 4: $2 > 2$ is FALSE. Loop terminates.

count = 3
🟡 IMPORTANT Q15 Array Sum

Array Stepped Index Accumulation

int data[5] = {2, 4, 6, 8, 10};
int sum = 0;
for (int i=0; i<4; i+=2) sum += data[i+1];

• $i=0$: Target `data[1]` = 4 $\rightarrow \text{sum} = 0 + 4 = 4$

• $i=2$: Target `data[3]` = 8 $\rightarrow \text{sum} = 4 + 8 = 12$

• $i=4$: Condition $4 < 4$ fails. Loop terminates.

sum = 12

Ecological Progression & Species Roles

Secondary Succession (Q45):

Progression after disturbance where SOIL REMAINS INTACT (e.g., clearing forest for cell tower $\rightarrow$ weeds $\rightarrow$ shrubs $\rightarrow$ trees).

Keystone Species (Q47):

Disproportionately large impact on ecosystem (e.g., Sea Otters controlling Urchins). Removal causes collapse!

Carrying Capacity (K) (Q48):

Max population environment can sustain indefinitely without habitat degradation.

🟠 HIGH-YIELD Q46, Q47 Definitions

Species Taxonomy Cards

Pioneer Species: First hardy organisms to colonize barren or heavily disrupted environments.

Invasive Species: Non-native organisms rapidly overpopulating and outcompeting native species.

Indicator Species: Highly sensitive organisms providing immediate clues about ecosystem health or pollution.

Resource Partitioning (Q46): Species divide shared resources to coexist (e.g., foraging upper canopy vs lower trunk).

🟡 IMPORTANT Q50 – Q54

Biogeochemical Cycles

Transpiration (Q50): Release of water vapor by plants through leaves into atmosphere.
Photosynthesis (Q51, Q53): $6\text{CO}_2 + 6\text{H}_2\text{O} + \text{sunlight} \rightarrow \text{C}_6\text{H}_{12}\text{O}_6 + 6\text{O}_2$. Removes atmospheric $\text{CO}_2$.
Nitrogen Fixation (Q52): Bacteria convert inert $\text{N}_2$ gas into biologically usable nitrates. Denitrification returns $\text{N}_2$ gas.
⚠️ PHOSPHORUS CYCLE EXCEPTION (Q54): Does NOT involve the ATMOSPHERE!
