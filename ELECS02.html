📐 CONSTANTS, UNITS & MAGIC NUMBERS

Thermal Voltage ($V_T$):

$V_T = \frac{kT}{q} \approx 26\text{ mV}$ at $T = 300\text{ K}$ ($27^\circ\text{C}$)

Diode Forward Drops ($V_F$):

Silicon (Si): $0.7\text{ V}$ | Germanium (Ge): $0.3\text{ V}$

Schottky: $0.2\text{ V} - 0.3\text{ V}$

Si Temp Coefficients:

$\frac{dV_{BE}}{dT} \approx -2.1\text{ mV/}^\circ\text{C}$ (or $-2\text{ mV/}^\circ\text{C}$)

$I_{CO}$ doubles every $10^\circ\text{C}$ rise

AC Dynamic Resistance ($r_d$):

$r_d = \frac{\eta V_T}{I_D} = \frac{26\text{ mV}}{I_D}$ (at $300\text{ K}$)

🌳 BOARD EXAM PROBLEM-SOLVING DECISION TREE "Which equation do I use?"

1. ZENER REGULATOR

Given $V_{in}, R_S, V_Z, R_L$:

  1. Check $V_{open} = V_{in} \frac{R_L}{R_S + R_L}$
  2. If $V_{open} \ge V_Z \implies$ Zener ON ($V_O = V_Z$)
  3. $I_S = \frac{V_{in} - V_Z}{R_S}$
  4. $I_Z = I_S - I_L$
  5. If $R_L$ removed ($I_L=0) \implies I_Z = I_S$ (MAX)
2. BJT DC BIASING

Given circuit diagram & $\beta$:

  1. KVL in Base-Emitter loop $\implies I_B$
  2. $I_C = \beta I_B$, $I_E = (\beta+1)I_B$
  3. $V_C = V_{CC} - I_C R_C$
  4. Check mode: $V_{BC} < 0.4\text{V} \implies$ Active
  5. If $V_{CE} \le 0.2\text{V} \implies$ Saturation
3. FET / MOSFET DC

Identify FET Type first:

  1. JFET / D-MOS: $I_D = I_{DSS}(1 - V_{GS}/V_P)^2$
  2. E-MOSFET: $I_D = k(V_{GS} - V_{th})^2$
  3. If $V_{GS} < V_P$ or $< V_{th} \implies I_D = 0$ (Cutoff)
  4. $V_{DS} = V_{DD} - I_D(R_D + R_S)$
4. SMALL SIGNAL & MILLER

Given $A_V$ & internal $C$:

  1. $C_{in(Miller)} = C_{gd}(1 - A_V)$
  2. $C_{in(total)} = C_{gs} + C_{in(Miller)}$
  3. $g_{m0} = \frac{2I_{DSS}}{|V_P|}$
  4. $g_m = g_{m0}\sqrt{I_D / I_{DSS}}$

🔴 FORMULA CARD ZENER MAX CURRENT
$$I_{ZM} = \frac{P_{D(\max)}}{V_Z}$$

VARIABLES: $P_{D(\max)}$ [W] = Max Power, $V_Z$ [V] = Zener Voltage

USE WHEN: Finding max safe Zener current before thermal damage.

EXAMPLE [Q4]: $V_Z = 6.8\text{V}, P_D = 500\text{mW} \implies I_{ZM} = \frac{500\text{mW}}{6.8\text{V}} = \mathbf{73.5\text{ mA}}$

⚠️ TRAP: Always express power in Watts and current in Amperes!

🟠 FORMULA CARD VARACTOR JUNCTION
$$C_J = \frac{C(0)}{\left(1 + \frac{V_R}{V_T}\right)^n} \quad \text{or} \quad \frac{C_1}{C_2} = \sqrt{\frac{V_{R2}}{V_{R1}}}$$

VARIABLES: $C(0)$ = zero-bias capacitance, $V_R$ = reverse bias, $n = 1/2$ (alloy junction)

USE WHEN: Calculating tuning capacitance vs tuning voltage.

EXAMPLE [Q15]: $C_1 = 36\text{pF}$ at $V_1 = 4\text{V}$. At $V_2 = 16\text{V} \implies C_2 = 36 \times \sqrt{4/16} = \mathbf{18\text{ pF}}$

⚠️ TRAP: $V_R \uparrow \implies C_J \downarrow$ (Inversely proportional!)

🎯 WAVESHAPING DEFINITIONS
CLIPPER (Limiter) [Q29]:

Cuts off portion of waveform. Diode conducts when $V_{in} \ge V_B + V_D = 2\text{V} + 0.7\text{V} = \mathbf{2.7\text{ V}}$.

CLAMPER (DC Restorer) [Q30, Q31]:

Shifts DC level. Uses $D + C + R$. $V_{p-p}$ remains unchanged! Positive peak at $0\text{V} \implies$ Negative Clamper.

PEAK DETECTOR [Q25]:

Consists of Diode + Capacitor. Captures peak AC voltage.

⚡ VOLTAGE QUADRUPLER [Q28]
$$V_{dc(peak)} = 4 \times V_m = 4 \times (V_{rms} \sqrt{2})$$

GIVEN: $V_{rms} = 30\text{ V}$

STEP 1: $V_m = 30 \times \sqrt{2} = 42.426\text{ V}$

STEP 2: $V_{out} = 4 \times 42.426\text{ V} = \mathbf{169.7\text{ V} \approx 170\text{ V}}$

⚠️ TRAP: Always convert $V_{rms}$ to peak $V_m$ first by multiplying by $\sqrt{2}$!

🔴 REGULATOR DEFINITION [Q33]
DROPOUT VOLTAGE = $V_{in(\min)} - V_{out}$

DEFINITION: Minimum input-to-output differential voltage required by a linear regulator to maintain regulation.

CAUSE OF REGULATION LOSS [Q10]: If input voltage drops below breakdown threshold, output drops below nominal $V_Z$.

🔴 FORMULA CARD BJT COLLECTOR VOLTAGE
$$I_C = \frac{\beta}{\beta + 1} I_E \quad \implies \quad V_C = V_{CC} - I_C R_C$$

EXAMPLE [Q43]: Given $I_E = 1\text{ mA}, R_C = 4.7\text{ k}\Omega, \beta = 100, V_{CC} = 10\text{ V}$

STEP 1: $I_C = \frac{100}{101} (1\text{ mA}) = 0.9901\text{ mA}$

STEP 2: $V_C = 10 - (0.9901\text{mA} \times 4.7\text{k}\Omega) = \mathbf{5.35\text{ V}}$

⚠️ TRAP [CLARIFICATION]: Do not assume $I_C = I_E$ if exact $\beta$ is given! Use $\frac{\beta}{\beta+1}$.

🟡 BIAS CIRCUITS STABILITY
FIXED BIAS [Q39, Q49]:

Poor stability! Temp $\uparrow \implies I_C \uparrow \implies$ Q-point shifts toward saturation (Thermal Runaway risk).

COLLECTOR FEEDBACK [Q50]:

Negative Feedback: $I_C \uparrow \implies V_C \downarrow \implies I_B \downarrow \implies I_C \downarrow$ (Stabilizes Q-point).

EMITTER DEGENERATION / BYPASS [Q41, Q42]:

Increasing $R_E$ stabilizes Q-point but reduces gain. $C_E$ bypasses $R_E$ for AC to restore high gain.

🟠 POWER AMPLIFIER CLASSES
Class A: $360^\circ$ conduction (High linearity, low efficiency)
Class B [Q36]: $180^\circ$ conduction (Pushed-pull)
Class AB: $>180^\circ, <360^\circ$ (Eliminates crossover)
Class C [Q48]: $<180^\circ$ conduction. Made linear by adding LC tuned tank!

🔴 TRANSCONDUCTANCE ($g_m$) [Q53, Q57]
$$g_m = \frac{\Delta I_D}{\Delta V_{GS}} = g_{m0} \sqrt{\frac{I_D}{I_{DSS}}} \quad \text{where } g_{m0} = \frac{2I_{DSS}}{|V_P|}$$

EXAMPLE [Q57]: $I_{DSS} = 10\text{mA}, g_{m0} = 4\text{mS}$. Find $I_D$ for $g_m = 0.6 g_{m0}$.

CALCULATION: $0.6 = \sqrt{\frac{I_D}{10\text{mA}}} \implies 0.36 = \frac{I_D}{10} \implies \mathbf{I_D = 3.6\text{ mA}}$

🟠 MILLER CAPACITANCE [Q56]
$$C_{in(Miller)} = C_{gd}(1 - A_V) \quad \implies \quad C_{in(total)} = C_{gs} + C_{in(Miller)}$$

EXAMPLE [Q56]: $A_V = -10, C_{gs} = 5\text{pF}, C_{gd} = 2\text{pF}$

STEP 1: $C_{in(Miller)} = 2\text{pF}(1 - (-10)) = 2(11) = 22\text{ pF}$

STEP 2: $C_{in(total)} = 5\text{pF} + 22\text{pF} = \mathbf{27\text{ pF}}$

🟡 FET OPERATING REGIONS
OHMIC / TRIODE REGION [Q34, Q54]:

$V_{DS} < V_{GS} - V_{th}$. MOSFET behaves like a voltage-controlled resistor.

SATURATION REGION:

$V_{DS} \ge V_{GS} - V_{th}$. Drain current is constant (Voltage-controlled current source).

SOURCE FOLLOWER (Common Drain) [Q51]:

$A_V \approx 1$ due to strong negative feedback from source resistor $R_S$.

⚠️ DON'T CONFUSE THESE — COMMON BOARD EXAM MULTIPLE CHOICE TRAPS ⚠️ HIGH ERROR RATE

TRAP 1: PIV of Center-Tapped vs Bridge Rectifier
Center-Tapped FW:

$PIV = 2 V_m$

Diode must withstand twice the peak secondary voltage!

Bridge FW [Q32]:

$PIV = V_m$

For $24\text{V}_{rms} \implies PIV = 24\sqrt{2} = \mathbf{34\text{ V}}$

TRAP 2: D-MOSFET vs E-MOSFET Channel
D-MOSFET [Q59]:

Has physical channel constructed during manufacturing.

Operates in D-mode & E-mode.

E-MOSFET [Q52]:

NO physical channel until $V_{GS} > V_{GS(th)}$.

Cutoff when $V_{GS} < V_{GS(th)}$.

TRAP 3: Diode Dynamic Resistance vs DC Current
Dynamic $r_d$ [Q20]:

$r_d = \frac{26\text{mV}}{I_D}$

As current $I_D \uparrow \implies$ resistance $r_d \mathbf{\downarrow}$

Transistor $r_o$ [Q40]:

Internal output resistance decreases as current increases significantly!

TRAP 4: Silicon Forward Voltage Temp Coefficient

RULE [Q22]: Forward voltage drop of a silicon diode DECREASES with temperature under constant current bias!

Rate: approx $-2.1\text{ mV/}^\circ\text{C}$. Higher temp $\implies$ lower forward turn-on voltage!
