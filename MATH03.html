MODULE 1: DE CLASSIFICATION, WRONSKIAN THEORY & LINEAR OPERATORS

Order vs. Degree rules, Arbitrary Constants, Wronskian Determinant, Superposition Test, Non-Linearity Criteria, and Lipschitz Uniqueness.

🌳 DECISION TREE: DETERMINING ORDER AND DEGREE OF ANY DE

STEP 1: FIND ORDER

Locate the highest derivative present in the equation (e.g., $\frac{d^3y}{dx^3} \implies \text{Order } 3$).

Order is ALWAYS a positive integer!
STEP 2: PREPARE FOR DEGREE

Clear all fractions, negative exponents, and radicals involving derivatives.

Example: Square both sides if $\sqrt{y'}$.
STEP 3: CHECK DEGREE TRAPS

If any derivative is inside $\sin(y')$, $e^{y'}$, or $\ln(y')$, the degree is UNDEFINED!

Otherwise, degree = exponent of highest derivative.
ORDER & DEGREE OF A DE 🔴 MUST MEMORIZE

Order: Order of the highest derivative present.

Degree: Exponent of highest-order derivative after clearing radical/fractional powers.

FORMULA / EXAMPLE (Q3 [NOTES]):
$$\left(\frac{d^3 y}{dx^3}\right)^2 + 4\sin\left(\frac{dy}{dx}\right) = x^3$$
  • Highest Derivative: $\frac{d^3y}{dx^3} \implies \mathbf{\text{Order } 3}$
  • Degree: UNDEFINED (transcendental $\sin(y')$ term)
⚠️ COMMON TRAP: Do not confuse order and degree! Degree can only be evaluated when DE is polynomial in derivatives.
ESSENTIAL ARBITRARY CONSTANTS 🟠 HIGH-YIELD

The order of a DE equals the number of essential (independent) arbitrary constants in its general solution family.

SOLVED EXAMPLE (Q4 [NOTES]):
$$y = C_1 e^{4x + C_2}$$

Simplify using exponent rules:

$$y = C_1 e^{C_2} e^{4x} = C e^{4x}$$

Result: 1 essential constant $\implies \mathbf{\text{First-Order DE!}}$

💡 RULE: $C_1 e^{C_2}$ is just a single constant $C$. Always simplify algebraically first before counting constants!
WRONSKIAN DETERMINANT TEST 🔴 MUST MEMORIZE

Tests linear independence of solution sets $f(x), g(x)$:

$$W(f,g) = \begin{vmatrix} f & g \\ f' & g' \end{vmatrix} = f g' - g f'$$
$$W \neq 0$$

Linearly INDEPENDENT

$$W = 0 \text{ everywhere}$$

Linearly DEPENDENT (Q1)

Q2 EXAMPLE [NOTES]: Evaluate $W(\cos x, \sin x)$ for $y'' + y = 0$: $$W = \begin{vmatrix} \cos x & \sin x \\ -\sin x & \cos x \end{vmatrix} = \cos^2 x + \sin^2 x = \mathbf{1}$$
LINEAR OPERATOR SUPERPOSITION 🔵 CONCEPTUAL

An operator $L$ is strictly linear if and only if it satisfies the Principle of Superposition:

$$L(c_1 y_1 + c_2 y_2) = c_1 L(y_1) + c_2 L(y_2)$$

Satisfies both Additivity ($L(y_1+y_2)=L(y_1)+L(y_2)$) and Homogeneity ($L(cy)=cL(y)$).

Q5 [NOTES]: Option B represents the exact mathematical proof of linearity.
NON-LINEAR DE IDENTIFICATION 🟠 HIGH-YIELD

A DE is NON-LINEAR if any of these conditions are met:

  • Dependent variable $y$ multiplied by derivative: $y \frac{dy}{dx}$ (Q14).
  • Power of $y$ or derivatives $\neq 1$: $y^2, (y')^3$.
  • Non-linear function of $y$: $\sin(y), e^y, \ln(y)$.
Q15 [NOTES]: $\frac{d^2\theta}{dt^2} + \sin(\theta) = 0$ is NON-LINEAR because of $\sin(\theta)$.
LIPSCHITZ CONSTANT (Q45) 🟡 IMPORTANT

Guarantees unique solution for $\frac{dy}{dt} = f(t,y)$:

$$L = \max \left| \frac{\partial f}{\partial y} \right|$$
Q45 SOLVED [NOTES]: For $\frac{dy}{dt} = 7y + \cos(t)$: $$\frac{\partial f}{\partial y} = \frac{\partial}{\partial y}(7y + \cos t) = 7 \implies \mathbf{L = 7}$$

MODULE 2: FIRST-ORDER DEs, ORTHOGONAL TRAJECTORIES & RL/RC TRANSIENTS

Separable, Homogeneous, Exact, Non-Exact Integrating Factors, Orthogonal Trajectories, Clairaut's Equation, and First-Order RL/RC Circuit Transients.

🌳 MASTER DECISION TREE: HOW TO SOLVE ANY FIRST-ORDER DE

1. SEPARABLE?

Can you split into $f(y)dy = g(x)dx$?

Action: $\int f(y)dy = \int g(x)dx + C$.
❌ $y' = y^2 + t^2$ CANNOT be separated! (Q8)
2. HOMOGENEOUS?

Is $M(tx,ty) = t^n M(x,y)$? (Q9)

Action: Sub $y = vx \implies dy = v dx + x dv$.

Guaranteed outcome: Reduces to Variable Separable! (Q10)

3. EXACT?

Does $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$? (Q11)

Action: $F(x,y) = \int M dx + g(y) = C$.

Physical meaning: Potential field $F(x,y) = \text{Voltage}$ (Q13).

4. LINEAR / BERNOULLI?

$y' + P(x)y = Q(x)y^n$

Linear ($n=0$): $I.F. = e^{\int P(x)dx}$
Bernoulli ($n \neq 0,1$): Sub $v = y^{1-n}$ (Q17).
INTEGRATING FACTOR TEST RATIOS 🔴 MUST MEMORIZE

If $M dx + N dy = 0$ is NOT exact ($\frac{\partial M}{\partial y} \neq \frac{\partial N}{\partial x}$):

Ratio for $x$ alone:

$$p(x) = \frac{M_y - N_x}{N} \implies \mu(x) = e^{\int p(x)dx}$$

Ratio for $y$ alone (Q12 [NOTES]):

$$p(y) = \frac{N_x - M_y}{M} \implies \mu(y) = e^{\int p(y)dy}$$

⚠️ TRAP: Note the swapped order of partial derivatives: $(N_x - M_y)$ for $p(y)$ vs $(M_y - N_x)$ for $p(x)$!
ORTHOGONAL TRAJECTORIES 🟠 HIGH-YIELD

Used to find electric field lines perpendicular to equipotential lines:

  1. Differentiate family $y = f(x,c)$ and eliminate $c \implies \left(\frac{dy}{dx}\right)_{\text{orig}}$.
  2. Replace $\frac{dy}{dx}$ with $-\frac{dx}{dy}$.
  3. Solve resulting DE for orthogonal family.
Q7 SOLVED [NOTES]: Equipotential $y = c x^2 \implies c = y/x^2$.
$\frac{dy}{dx} = 2cx = 2(y/x^2)x = \frac{2y}{x}$.
Orthogonal Field Line DE: $\mathbf{\frac{dy}{dx} = -\frac{x}{2y}}$
CIRCLES TANGENT TO X-AXIS (Q6) 🟡 IMPORTANT

Circles centered on y-axis tangent to x-axis at $(0,0)$:

$$x^2 + (y-r)^2 = r^2 \implies x^2 + y^2 - 2ry = 0$$

Differentiate to eliminate radius parameter $r$:

$$(x^2 - y^2)y' - 2xy = 0$$
RL CIRCUIT TRANSIENT ANALYSIS 🔴 MUST MEMORIZE
GOVERNING DE:

$$L \frac{dI}{dt} + R I = V(t) \implies \frac{dI}{dt} + \frac{R}{L}I = \frac{V(t)}{L}$$

Integrating Factor (Q16): $$I.F. = e^{\frac{R}{L}t}$$

Time Constant ($\tau$): $$\tau = \frac{L}{R} \text{ [seconds]}$$

Q32 SOLVED [NOTES]: $L=50\text{ mH}, R=25\ \Omega, I_0=2\text{ A}$.
$\tau = \frac{50\times 10^{-3}}{25} = 2\text{ ms}$. At $t=0.5\text{ ms}$:
$$i(t) = 2 e^{-0.5/2} = 2 e^{-0.25} = \mathbf{1.56\text{ A}}$$
RC CIRCUIT TRANSIENT ANALYSIS 🔴 MUST MEMORIZE
GOVERNING DE:

$$R \frac{dq}{dt} + \frac{1}{C} q = V_{dc}$$

Time Constant ($\tau$): $$\tau = R C \text{ [seconds]}$$

Q35 & Q36 SOLVED [NOTES]:

• Transient Portion: Dictated by complementary solution $y_c(t) = C e^{-t/RC}$ (Q35).

• Q36: $0.5 \frac{di}{dt} + 10i = 24 \implies \tau = \frac{L}{R} = \frac{0.5}{10} = \mathbf{0.05\text{ s}}$, $I_{ss} = \frac{24}{10} = \mathbf{2.4\text{ A}}$.

CLAIRAUT'S EQUATION TRICK 🟡 IMPORTANT

Form: $$y = x y' + f(y')$$

BOARD EXAM INSTANT SOLUTION TRICK:

Replace derivative $y'$ with constant $c$!

$$y = c x + f(c)$$

Q39 SOLVED [NOTES]: $y = x y' + (y')^2 \implies \mathbf{y = c x + c^2}$

MODULE 3: SECOND-ORDER DEs, RLC DAMPING & RESONANCE

Characteristic Equations, Damping Regimes, Natural vs Damped Frequencies, Resonance, and Series vs Parallel RLC Damping Behaviors.

⚡ SECOND-ORDER SYSTEM DAMPING REGIMES & RLC COMPARISON

DAMPING REGIME CHARACTERISTIC ROOTS ($m_1, m_2$) DAMPING RATIO ($\zeta$) SERIES RLC CONDITION PHYSICAL / GRAPHICAL RESPONSE
OVERDAMPED Real & Distinct ($m_1 \neq m_2$) $$\zeta > 1$$ $$R^2 > \frac{4L}{C}$$ Sluggish exponential decay, zero oscillation.
CRITICALLY DAMPED Real & Repeated ($m_1 = m_2 = -a$) $$\zeta = 1$$ $$R^2 = \frac{4L}{C} \text{ (Q27)}$$ Returns to equilibrium fastest without oscillating (Q26).
UNDERDAMPED Complex Conjugates ($\alpha \pm j\omega_d$) $$0 < \zeta < 1$$ $$R^2 < \frac{4L}{C}$$ Exponentially decaying sinusoid (Q24, Q28).
UNDAMPED (PURE RESONANCE) Purely Imaginary ($\pm j\omega_0$) $$\zeta = 0$$ $$R = 0$$ Continuous, un-decaying sinusoid (Q37).
SERIES VS PARALLEL RLC DAMPING ⚠️ COMMON TRAP
SERIES RLC CIRCUIT:

$$\alpha = \frac{R}{2L}, \quad \zeta = \frac{R}{2}\sqrt{\frac{C}{L}}$$

Increasing $R \implies$ INCREASES damping!

PARALLEL RLC CIRCUIT (Q38 [NOTES]):

$$\alpha = \frac{1}{2RC}, \quad \zeta = \frac{1}{2R}\sqrt{\frac{L}{C}}$$

Increasing $R \implies$ DECREASES damping ratio $\zeta$!

RLC FREQUENCY RELATIONSHIPS 🔴 MUST MEMORIZE
Undamped Natural Frequency ($\omega_n$):

$$\omega_n = \frac{1}{\sqrt{LC}} \text{ [rad/s]}$$

Damped Frequency ($\omega_d$):

$$\omega_d = \sqrt{\omega_n^2 - \alpha^2} = \omega_n \sqrt{1 - \zeta^2}$$

Q30 SOLVED [NOTES]: $x(t) = e^{-3t}(C_1 \cos 4t + C_2 \sin 4t)$
$\alpha = 3, \omega_d = 4 \implies \omega_n = \sqrt{3^2 + 4^2} = \mathbf{5\text{ rad/s}}$.
Damping ratio $\zeta = \frac{\alpha}{\omega_n} = \frac{3}{5} = \mathbf{0.600}$.
PURE RESONANCE (Q23) 🟠 HIGH-YIELD

Solving $y'' + \omega_0^2 y = F_0 \sin(\omega t)$ when forcing frequency equals natural frequency ($\omega = \omega_0$):

Standard trial $A\cos(\omega t) + B\sin(\omega t)$ fails. Must multiply trial by $t$!

$$y_p(t) = A t \cos(\omega_0 t) + B t \sin(\omega_0 t)$$

Q23 SOLVED [NOTES]: $y'' + 9y = 5\sin(3t) \implies \mathbf{y_p(t) = A t \cos(3t) + B t \sin(3t)}$

$$\frac{\partial u}{\partial t} = c^2 \frac{\partial^2 u}{\partial x^2}$$

Models heat flow, charge carrier diffusion in semiconductors.

HYPERBOLIC
1D / 2D WAVE EQUATION

$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}$$

Models EM wave propagation, transmission lines.

$$\nabla^2 u = f(x,y) \text{ (Poisson)}$$

VAN DER POL OSCILLATOR (Q40) 🔵 CONCEPTUAL

Non-linear equation modeling self-sustaining electronic oscillators (e.g., varactor diode circuits):

$$\frac{d^2 v}{dt^2} + (v^2 - 1)\frac{dv}{dt} + v = 0$$

Features non-linear damping: adds energy at low amplitudes ($|v| < 1$) and dissipates energy at high amplitudes ($|v| > 1$), creating stable limit cycles.
