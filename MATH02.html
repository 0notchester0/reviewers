CORE STANDARD INTEGRAL FORMULAS

1. Inverse Sine Form
$$\int \frac{dx}{\sqrt{a^2 - x^2}} = \sin^{-1}\left(\frac{x}{a}\right) + C$$

USE WHEN: Radical term $\sqrt{a^2-x^2}$ is in denominator.

TRAP: No multiplier fraction $1/a$ outside $\sin^{-1}$!

2. Inverse Tangent Form
$$\int \frac{dx}{x^2 + a^2} = \frac{1}{a} \tan^{-1}\left(\frac{x}{a}\right) + C$$

USE WHEN: Quadratic sum $x^2+a^2$ with no square root.

TRAP: Do NOT forget the leading factor $\frac{1}{a}$!

3. Natural Log Derivative Derivative
$$\int \frac{2x}{x^2 + a^2} dx = \ln(x^2 + a^2) + C$$

USE WHEN: Numerator is exact derivative of denominator.

TRAP: Do not confuse with inverse tangent form!

4. Difference of Squares Log Form
$$\int \frac{dx}{x^2 - a^2} = \frac{1}{2a} \ln\left|\frac{x-a}{x+a}\right| + C$$

USE WHEN: Denominator is $x^2 - a^2$ (Q2).

TRAP: Order in log fraction is strictly $\frac{x-a}{x+a}$!

🟠 HIGH-YIELD

INVERSE TRIGONOMETRIC DERIVATIVES

Arcsine Derivative
$$\frac{d}{dx}(\sin^{-1} x) = \frac{1}{\sqrt{1 - x^2}}$$
Arccosine Derivative
$$\frac{d}{dx}(\cos^{-1} x) = -\frac{1}{\sqrt{1 - x^2}}$$
Arctangent Derivative
$$\frac{d}{dx}(\tan^{-1} x) = \frac{1}{1 + x^2}$$
Arccotangent Derivative
$$\frac{d}{dx}(\cot^{-1} x) = -\frac{1}{1 + x^2}$$
Arcsecant Derivative
$$\frac{d}{dx}(\sec^{-1} x) = \frac{1}{|x|\sqrt{x^2 - 1}}$$
Arccosecant Derivative
$$\frac{d}{dx}(\csc^{-1} x) = -\frac{1}{|x|\sqrt{x^2 - 1}}$$

FUNDAMENTAL THEOREMS & LEIBNIZ RULE

Second Fundamental Theorem of Calculus (FTC-2) 🔴 MEMORIZE
$$\int_{a}^{b} f(x) dx = F(b) - F(a)$$

Mandatory Condition (Q20): $f(x)$ MUST be strictly continuous on the closed interval $[a, b]$. [NOTES]

Leibniz Rule (Differentiation Under Integral) ⚠️ HIGH TRAP
$$\frac{d}{dx} \int_{g(x)}^{h(x)} f(t) dt = f(h(x))\cdot h'(x) - f(g(x))\cdot g'(x)$$
TRAP (Q18, Q19): Never forget to multiply $f(h(x))$ by $h'(x)$ and $f(g(x))$ by $g'(x)$!
SECTION A

ADVANCED INTEGRATION TECHNIQUES

LIATE RULE (IBP)

🔴 MUST

Formula: $\int u \, dv = uv - \int v \, du$. Priority sequence for selecting $u$:

L - Logarithmic $\ln x, \log_b x$
I - Inverse Trig $\sin^{-1} x, \tan^{-1} x$
A - Algebraic $x^n, 3x^2, \sqrt{x}$
T - Trigonometric $\sin x, \cos x$
E - Exponential $e^x, 2^x$
Cyclic IBP Trick (Q12): When integral reappears (e.g. $\int e^x \cos x dx$), add original integral $I$ to LHS and divide by combined multiplier!

PARTIAL FRACTION DECOMPOSITION (PFD)

🟠 HIGH-YIELD
Denominator Factor Type Assumed Partial Fraction Form Example / Board Exam Context
Distinct Linear $(x - a)$ $\frac{A}{x - a}$ 1 constant per distinct factor
Repeated Linear $(x - a)^k$ $\frac{A_1}{x - a} + \frac{A_2}{(x - a)^2} + \dots + \frac{A_k}{(x - a)^k}$ $\frac{5x-2}{(x+2)^3} \implies 3$ constants (Q14)
Irreducible Quadratic $(x^2 + a^2)$ $\frac{Ax + B}{x^2 + a^2}$ $\frac{4x^2-3x+1}{(x-2)(x^2+9)} \implies \frac{A}{x-2} + \frac{Bx+C}{x^2+9}$ (Q13)
Repeated Quadratic $(x^2 + a^2)^2$ $\frac{Ax + B}{x^2 + a^2} + \frac{Cx + D}{(x^2 + a^2)^2}$ $\frac{5x^3-2x+1}{(x^2+4)^2}$ (Q15)

TRIGONOMETRIC SUBSTITUTION DECISION TREE

🔴 MUST MEMORIZE
Radical Form: $\sqrt{a^2 - x^2}$
• Substitute: $x = a \sin \theta$
• Differential: $dx = a \cos \theta d\theta$
• Identity: $1 - \sin^2 \theta = \cos^2 \theta$
Radical Form: $\sqrt{a^2 + x^2}$ (Q16)
• Substitute: $x = a \tan \theta$
• Differential: $dx = a \sec^2 \theta d\theta$
• Identity: $1 + \tan^2 \theta = \sec^2 \theta$
Radical Form: $\sqrt{x^2 - a^2}$ (Q17)
• Substitute: $x = a \sec \theta$
• Differential: $dx = a \sec \theta \tan \theta d\theta$
• Identity: $\sec^2 \theta - 1 = \tan^2 \theta$

SECTION E, F, G

ARC LENGTH, SOLIDS OF REVOLUTION & CENTROIDS

DISK / WASHER vs. SHELL METHOD

🔴 MUST
Disk / Washer Method (Slice $\perp$ Axis)
$V = \pi \int_a^b (R_{out}^2 - r_{in}^2) d(\text{var})$
• Revolve around Horizontal $\to dx$ | Vertical $\to dy$
Cylindrical Shell Method (Slice $\parallel$ Axis)
$V = 2\pi \int_a^b (\text{radius})(\text{height}) d(\text{var})$
• Revolve around Horizontal $\to dy$ | Vertical $\to dx$ (Q36)

ARC LENGTH & CENTROID FORMULAS

🟠 HIGH-YIELD
Parametric Arc Length (Q33):
$$L = \int_{t_1}^{t_2} \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} dt$$
Microstrip Patch Antenna Centroid ($\bar{y}$):
$$\bar{y} = \frac{\frac{1}{2}\int_{0}^{\pi}\sin^2(x)dx}{\int_{0}^{\pi}\sin(x)dx} = \frac{\pi/4}{2} = \frac{\pi}{8} \quad \text{(Q40)}$$

DON'T CONFUSE THESE! (SIDE-BY-SIDE COMPARISONS)

Trapezoidal vs. Simpson's 1/3 Rule Requirements
Trapezoidal Rule • Works for ANY $n \ge 1$
• Supports uneven spacing
• Linear interpolation
• $O(h^2)$ global error
Simpson's 1/3 Rule • Requires EVEN $n$
• Requires uniform $h$
• Parabolic arc approximation
• $O(h^4)$ global error
Revolutions About Vertical Axis ($y$-axis or $x = k$)
Washer Method • Slices are Horizontal
• Thickness is $dy$
• Integrate w.r.t. $y$
• Formula: $\pi \int (R^2 - r^2) dy$
Shell Method • Slices are Vertical
• Thickness is $dx$
• Integrate w.r.t. $x$
• Formula: $2\pi \int (\text{rad})(\text{ht}) dx$

TOP 5 BOARD EXAM TRAPS TO AVOID

1. Radian Mode Missing

Evaluating trig or inverse trig integrals in DEGREE mode on calculator will give wrong choices!

2. Chain Rule in Leibniz

When differentiating $\int_a^{g(x)} f(t) dt$, never forget to multiply by $g'(x)$!

3. Points vs Subintervals

Simpson's requires EVEN subintervals $n$, which means ODD total points $N = n + 1$.

4. Shifted Axis Radius

When revolving around $y=5$ or $x=-2$, radius is $|5 - y|$ or $|x - (-2)| = x+2$.

5. $p$-Series Boundary

$p \le 1$ strictly DIVERGES; $p > 1$ CONVERGES. Do not invert the inequality!

CALTECH CALCULATOR SHORTCUTS (BOARD EXAM TRICKS)

1. Indefinite Integrals via Differentiation
  1. Choose test values (e.g. $x = 2.3$, $a = 1.5$).
  2. Evaluate integrand at $x$ using calculator.
  3. Take $d/dx$ of each answer choice at $x$ using d/dx key.
  4. MATCH: Derivative of correct choice == Integrand value!
2. Numerical Integration Iteration Formula
• Trapezoidal: $A = A + \frac{h}{2}[f(x) + f(x+h)] : x = x + h$
• Simpson's: $A = A + \frac{h}{3}[f(x) + 4f(x+h) + f(x+2h)] : x = x + 2h$
