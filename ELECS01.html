THEVENIN'S THEOREM

🔴 MEMORIZE

Any linear, active, bilateral 2-terminal network can be replaced by an equivalent circuit containing a single voltage source $V_{th}$ in series with $R_{th}$.

$V_{th}$: Open-circuit voltage across load terminals.
$R_{th}$: Resistance looking back into terminals with all independent sources killed (Voltage $\rightarrow$ Short, Current $\rightarrow$ Open).
USE WHEN: Finding load current for variable load resistor $R_L$. $I_L = \frac{V_{th}}{R_{th} + R_L}$.

MAX POWER TRANSFER

🔴 MEMORIZE

Maximum power is transferred from source to load when load resistance equals source Thevenin resistance ($R_L = R_{th}$).

$$P_{max} = \frac{V_{th}^2}{4 R_{th}}$$
At Max Power: Efficiency $\mathbf{\eta = 50\%}$
BOARD QUESTION (p.2): Why match $R_L$ to $R_{th}$? To achieve maximum power delivery to load (despite 50% efficiency loss in internal resistance).

MILLMAN'S THEOREM

🟠 HIGH YIELD

Converts multiple parallel voltage sources with internal series resistances into a single equivalent voltage source $V_m$ and series resistance $R_m$.

$$V_m = \frac{\sum_{i=1}^n \frac{V_i}{R_i}}{\sum_{i=1}^n \frac{1}{R_i}}$$
$R_m = \frac{1}{\sum (1/R_i)}$
BOARD QUESTION (p.2): Finding voltage at single node where 4 branches (each with voltage source & series resistor) meet $\rightarrow$ Millman's is MOST EFFICIENT!

SUPERPOSITION THEOREM

🟡 IMPORTANT

In a bilateral linear network, total response (current or voltage) is the algebraic sum of responses caused by each independent source acting alone.

• Voltage Sources: Replace with SHORT CIRCUIT (0V)
• Current Sources: Replace with OPEN CIRCUIT (0A)
TRAP (p.2): Fails if circuit contains NON-LINEAR elements (e.g. diode, varistor) or when directly calculating power ($P = I^2 R$).

RECIPROCITY & COMPENSATION

🔵 CONCEPT
Reciprocity: Single voltage source $V$ in branch A produces current $I$ in branch B. Moving $V$ to branch B produces SAME current $I$ in branch A ($V/I = \text{Transfer Impedance}$).
Compensation: If branch resistance changes from $R$ to $R + \Delta R$, current change in network equals inserting a compensating voltage source $V_c = -I \Delta R$ in series with that branch.
Tellegen's Theorem: Power conservation law $\sum_{k=1}^b v_k i_k = 0$ applies to ANY network regardless of linearity or components.

TOPOLOGY: MESH & NODE

🔴 MEMORIZE
INDEPENDENT MESH EQUATIONS REQUIRED
$$l = b - n + 1$$
$b = \text{branches}$, $n = \text{nodes}$, $l = \text{independent loops/meshes}$
Supermesh: Created when a current source is shared between two meshes. Omit current source, apply KVL to outer loop.
Supernode: Created when an ideal voltage source is connected between two non-reference nodes. Enclose source in boundary, apply KCL.
BOARD QUESTION (p.2): How to find exact current through ideal voltage source in supernode? Use KCL at one of the connected original nodes!

SPECIAL RESISTOR CONFIGURATIONS & MATRIX SHORTCUTS

3×3 Series-Parallel Matrix (p.2)

3 parallel branches, each containing 3 series resistors of equal value $R$.

$R_{branch} = 3R \implies R_{net} = \frac{3R}{3} = \mathbf{R}$
Infinite Resistor Ladder (p.3)

Repeating sections with series $1\ \Omega$ and shunt $2\ \Omega$ resistors.

$R_{in} = 1 + (2 \parallel R_{in}) \implies R_{in}^2 - R_{in} - 2 = 0 \implies \mathbf{R_{in} = 2\ \Omega}$
Parallel Resistor Addition (p.2)

Adding an additional resistor in parallel to any resistive network.

$\mathbf{R_{total}\ \text{DECREASES}} \implies \mathbf{I_{total}\ \text{INCREASES}}$

RESONANCE COMPARISON: SERIES vs PARALLEL RLC

🔴 CRITICAL BOARD TOPIC
SERIES RLC RESONANCE Acceptor Circuit
  • Resonant Frequency: $f_r = \frac{1}{2\pi\sqrt{LC}}$
  • Reactance Condition: $X_L = X_C \implies Z = R$
  • Impedance $Z$: MINIMUM ($Z_{min} = R$)
  • Line Current $I$: MAXIMUM ($I_{max} = \frac{V}{R}$)
  • Power Factor: UNITY ($\mathbf{PF = 1.0}$)
  • Phase Angle: $\theta = 0^\circ$ ($V$ and $I$ are IN PHASE)
  • Quality Factor: $Q = \frac{\omega_r L}{R} = \frac{1}{\omega_r C R} = \frac{f_r}{\text{BW}}$
PARALLEL RLC RESONANCE Rejector / Tank Circuit
  • Resonant Frequency: $f_r = \frac{1}{2\pi\sqrt{LC}}$
  • Susceptance Condition: $B_L = B_C \implies Y = G$
  • Impedance $Z$: MAXIMUM ($Z_{max} = R_p = \frac{L}{C R}$)
  • Line Current $I$: MINIMUM
  • Power Factor: UNITY ($\mathbf{PF = 1.0}$)
  • Phase Angle: $\theta = 0^\circ$ ($V$ and $I$ are IN PHASE)
  • Energy Behavior: Oscillates between $L$ & $C$ (Tank Circuit)
⚠️ PARALLEL RESONANT CIRCUIT FREQUENCY TRAP (p.4, Q39) BOARD TRAP

A parallel resonant circuit is CAPACITIVE at $f = 100\text{ Hz}$. At what frequency range will it be INDUCTIVE?

• Below Resonance ($f < f_r$): Inductive reactance is smaller ($X_L < X_C$), so current flows through $L \rightarrow$ Circuit is INDUCTIVE.
• Above Resonance ($f > f_r$): Capacitive reactance is smaller ($X_C < X_L$) $\rightarrow$ Circuit is CAPACITIVE.
$\implies$ If it is capacitive at $100\text{ Hz}$, it must be inductive at frequencies SOMEWHERE BELOW 100 Hz!

ULTIMATE RAPID REVIEW & BOARD EXAM TRAP BANK

High-speed review table, commonly confused pairs, and board exam trap callouts

FINAL DRILL

DON'T CONFUSE THESE (BOARD EXAM COMPARISONS)

PMMC vs MOVING IRON
PMMC: DC only, measures average value, linear scale ($\theta \propto I$).
Moving Iron: AC & DC, measures RMS value, non-linear square scale ($\theta \propto I^2$).
⚠️ Trap: Half-wave rectified signal on PMMC ammeter reads $I_{avg} = I_m / \pi$.
REACTANCE ($X$) vs SUSCEPTANCE ($B$)
Capacitive: $X_C$ is negative ($-j$), but $B_C$ is POSITIVE ($+j$)!
Inductive: $X_L$ is positive ($+j$), but $B_L$ is NEGATIVE ($-j$)!
⚠️ Trap: Reactance and Susceptance have OPPOSITE SIGNS for the same reactive element.
SERIES vs PARALLEL RESONANCE
Series: $Z$ is MINIMUM ($Z=R$), Line Current $I$ is MAXIMUM.
Parallel: $Z$ is MAXIMUM ($Z=R_p$), Line Current $I$ is MINIMUM.
⚠️ Both have Unity Power Factor ($PF=1.0$) and $\theta = 0^\circ$ at resonance!
