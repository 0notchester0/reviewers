PART 01

Probability Foundations, Continuous Density & Discrete Selectors

🔴 CRITICAL BASELINE
KOLMOGOROV'S THREE AXIOMS [NOTES Q1]
Axiom 1 (Non-Negativity):
$$P(A) \ge 0 \quad \text{for any event } A$$
Axiom 2 (Total Measure / Certainty):
$$P(S) = 1 \quad \text{where } S = \text{entire sample space}$$
Axiom 3 (Additivity):
$$\text{If } A \cap B = \emptyset \implies P(A \cup B) = P(A) + P(B)$$
⚠️ TRAP: Probability of the whole universe $S$ is strictly $1.000$, never $\infty$ or dependent on event counts.
CONTINUOUS PDF & EXPECTED VALUE [NOTES Q2, Q16]
Normalized Single-Variable PDF Condition:
$$\int_{-\infty}^{\infty} f(x) \, dx = 1$$
Expected Value (Mean / Average):
$$\mu = E[X] = \int_{-\infty}^{\infty} x \cdot f(x) \, dx$$
If $f(x)$ is symmetric/even and domain is $[-a, a]$, odd integrand $x f(x) \implies E[X] = 0$.
EXACT SINGLE-POINT PROBABILITY: $$P(X = c) = \int_{c}^{c} f(x) \, dx = 0 \quad \text{⚠️ [ALWAYS ZERO]}$$
PHYSICAL SENSE: Hitting exactly $120.0000\text{ V}$ has 0 probability; probability only exists across intervals $\int_{a}^{b} f(x)dx$.
JOINT & MARGINAL PDF CALCULUS [NOTES Q3]
Joint PDF Normalization:
$$\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} f(x,y) \, dy \, dx = 1$$
Marginal PDF of X (Integrate out y):
$$f_X(x) = \int_{\text{all } y} f(x,y) \, dy$$
Marginal PDF of Y (Integrate out x):
$$f_Y(y) = \int_{\text{all } x} f(x,y) \, dx$$
Board Drill: $f(x,y) = x+y$ on $[0,1]^2$.
$f_X(x) = \int_0^1 (x+y)dy = [xy + \frac{y^2}{2}]_0^1 = \mathbf{x + \frac{1}{2}}$.

⚡ DISCRETE PROBABILITY DISTRIBUTION SELECTOR & COMPARISON

[NOTES Q14, Q15]
BINOMIAL WITH Replacement
Conditions: Fixed $n$ independent trials, exactly 2 outcomes (pass/fail), constant probability $p$.
$$P(X=x) = \binom{n}{x} p^x (1-p)^{n-x}$$
Mean: $\mu = np$
Var: $\sigma^2 = np(1-p)$
ECE App: Batch testing components sampled with replacement or from massive population.
HYPERGEOMETRIC WITHOUT Replacement
Conditions: Finite population $N$, known total defects $K$, sample $n$ drawn without replacement. Trials are dependent!
$$P(X=k) = \frac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}}$$
Mean: $\mu = n\frac{K}{N}$
[NOTES Q14]: Tray of $N=20$ microprocessors, $K=4$ defective. Pick $n=5$ without replacement. Formula gives exact probability of $k=2$.
POISSON Continuous Continuum / Low p
Conditions: Count of rare independent events over a continuous interval (time, area, length). Very large $n$, very small $p$.
$$P(X=x) = \frac{\lambda^x e^{-\lambda}}{x!}$$
Mean: $\mu = \lambda$
Var: $\sigma^2 = \lambda$ (Equal!)
[NOTES Q15]: Number of microscopic silicon wafer surface defects per $\text{m}^2$. Independent spatial distribution.
RAPID TEST:
Are samples drawn from finite batch WITHOUT replacement? → Hypergeometric
Defects across continuous area/time/volume ($\text{m}^2$, seconds)? → Poisson
Fixed independent yes/no trials with constant probability $p$? → Binomial
CHEBYSHEV'S INEQUALITY (DISTRIBUTION-FREE BOUND)
🔴 [NOTES Q17]
Guaranteed Probability Minimum:
$$P(|X - \mu| < k\sigma) \ge 1 - \frac{1}{k^2}$$
Valid for ANY distribution (even skewed!) where $k > 1$.
• $\mu$ = Mean; $\sigma$ = Standard deviation ($\sigma = \sqrt{\text{Var}}$).
• $k$ = Number of standard deviations: $k = \frac{\text{Boundary distance}}{\sigma}$.
• If $k = 2 \implies P \ge 1 - \frac{1}{4} = 75.00\%$.
• If $k = 3 \implies P \ge 1 - \frac{1}{9} = \mathbf{88.89\%}$ ($0.8889$).
BOARD DRILL [NOTES Q17]:
Abstract signal $V$ has $\mu=0$, $\text{Var}=\sigma^2=4 \implies \sigma=2$.
Probability that magnitude $|V| < 6$:
$$k = \frac{6}{\sigma} = \frac{6}{2} = 3 \implies P \ge 1 - \frac{1}{3^2} = \mathbf{0.8889}$$

Metrology, Metric Linear Transformation, Shape & Robustness

🔴 BOARD FAVORITE
METROLOGY: ACCURACY VS. PRECISION [NOTES Q5]
LOW Acc / LOW Prec High Bias + High Noise
LOW Acc / HIGH Prec Probe Offset (+50mV Bias)
HIGH Acc / HIGH Prec Zero Bias + Minimal Noise
⚠️ THE CLASSIC SCOPE TRAP [NOTES Q5]:
An uncalibrated oscilloscope probe injects a fixed $+50\text{ mV}$ DC offset:
Accuracy: Degraded!
$\text{Accuracy} \propto \frac{1}{\text{Bias (Error)}}$
Precision: Unaffected!
$\text{Precision} \propto \frac{1}{\text{Var}(\sigma^2)}$
LINEAR OPERATOR LAWS: Var(aX + b) & Cov(X,Y) [NOTES Q9, Q11]
1. Variance Under Scaling + Offset: $$\text{Var}(aX + b) = a^2 \text{Var}(X)$$
The constant baseline $b$ has ZERO variance! The scalar $a$ is SQUARED (any negative sign disappears!).
2. Fundamental Covariance Identity: $$\text{Cov}(X,Y) = E[XY] - E[X]E[Y] \iff E[XY] = \text{Cov}(X,Y) + E[X]E[Y]$$
[NOTES Q9 DRILL]: $\text{Var}(X)=15$. Find $\text{Var}(-2X + 10)$:
$$\text{Var}(-2X + 10) = (-2)^2 \cdot 15 = 4 \times 15 = \mathbf{60}$$
[NOTES Q11 DRILL]: $E[X]=5, E[Y]=4, \text{Cov}(X,Y)=-2$. Find $E[XY]$:
$$-2 = E[XY] - (5)(4) \implies E[XY] = 20 - 2 = \mathbf{18}$$
SHAPE 1: SKEWNESS (HORIZONTAL ASYMMETRY) [NOTES Q12]
Rule of thumb: The Mean is always dragged toward the long tail! Direction of skewness is named by the tail, NOT the peak.
LEFT / NEGATIVE
$\text{Tail} \leftarrow \text{Left}$
$\text{Mean} < \text{Med} < \text{Mode}$
SYMMETRIC
$\text{Normal Bell}$
$\text{Mean} = \text{Med} = \text{Mode}$
RIGHT / POSITIVE
$\text{Tail} \rightarrow \text{Right}$
$\text{Mode} < \text{Med} < \text{Mean}$
[NOTES Q12]: Positively skewed microprocessor operational lifespans strictly satisfy: $\mathbf{\text{Mode} < \text{Median} < \text{Mean}}$.
SHAPE 2: KURTOSIS (PEAKEDNESS & TAIL FATNESS) [NOTES Q13]
Governed by kurtosis parameter $k$ relative to Gaussian reference ($k=3$):
LEPTOKURTIC
$k > 3$
Sharp peak, fat/heavy tails. Impulsive noise!
MESOKURTIC
$k = 3$
Zero excess kurtosis. Standard AWGN Normal.
PLATYKURTIC
$k < 3$
Flatter peak, thin/light tails. Uniform noise.
[NOTES Q13]: Signal harmonics modeled as Leptokurtic have a sharper peak and heavier tails than Gaussian distribution.
DESCRIPTIVE METRIC OUTLIER RESISTANCE [NOTES Q8]
Extreme voltage spikes injected into the upper tail ($10, 11, 11, 11, 12, 12, 13 \rightarrow \mathbf{100}$):
Metric Sensitivity Mathematical Reason
Arithmetic Mean ($\bar{x}$) ❌ Severely Inflated Sum $\sum x_i$ is directly dragged by the outlier.
Range ($R = x_{\max}-x_{\min}$) ❌ Destroyed Strictly dependent on the single maximum value.
Sample Variance ($s^2$) ❌ Explodes Squared deviations $(x_i - \bar{x})^2$ magnify spikes.
Interquartile Range (IQR) ✅ IMMUNE (Robust) $\text{IQR} = Q_3 - Q_1$ only tracks middle 50%!
Median ✅ IMMUNE (Robust) Positional rank metric; ignores extreme tail magnitude.
SAMPLING METHODOLOGIES TAXONOMY [NOTES Q6, Q7]
PROBABILITY SAMPLING
  • Simple Random: Equal, independent chance for all.
  • Systematic: 1st random, then every $k$-th unit.
  • Stratified: Random sampling within every stratum.

  • Convenience: Easiest accessibility/proximity.

  • Snowball (Networking): Chain referrals [NOTES Q7: tracing illegal taps].
PART 03

Central Limit Theorem, Standard Errors & Confidence Intervals

🔴 FORMULA HEAVY
CENTRAL LIMIT THEOREM (CLT) [NOTES Q18]
For ANY parent population with mean $\mu$ and finite variance $\sigma^2$, as sample size $n \ge 30$, the sample mean distribution $\bar{x}$ approaches Normal:
$$\mu_{\bar{x}} = \mu_{\text{pop}}$$ $$\text{Var}(\bar{x}) = \sigma_{\bar{x}}^2 = \frac{\sigma^2}{n}$$
[NOTES Q18 Drill]: Parent is non-normal, right-skewed with $\mu=50, \sigma^2=100, n=400$.
$\bar{x}$ is Approx. Normal with mean $50$ and variance $\sigma_{\bar{x}}^2 = \frac{100}{400} = \mathbf{0.25}$.
STANDARD ERROR FORMULAS [NOTES Q19, Q20]
SE of the Mean: $$\text{SE}_{\bar{x}} = \sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$$ [Q19]: $\sigma=3\,\Omega, n=36 \implies \text{SE} = \frac{3}{6} = \mathbf{0.50\,\Omega}$
SE of a Proportion: $$\text{SE}_{\hat{p}} = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$ [Q20]: $20/400=0.05 \implies \text{SE} = \sqrt{\frac{0.05(0.95)}{400}} = \mathbf{0.0109}$
MARGIN OF ERROR & SAMPLE SCALING [NOTES Q24]
$$\text{ME} = z \cdot \frac{\sigma}{\sqrt{n}} \implies \text{ME} \propto \frac{1}{\sqrt{n}} \implies n \propto \frac{1}{\text{ME}^2}$$
CRITICAL SCALING THEOREM:
To cut the Margin of Error in HALF ($\text{ME}_2 = \frac{1}{2}\text{ME}_1$):
$$n_2 = (2)^2 n_1 = \mathbf{4 n_1} \quad \text{(Scale sample size by 4!)}$$
To cut ME by a factor of $k$, you must multiply sample size by $k^2$.

📐 TWO-SIDED CONFIDENCE INTERVAL GEOMETRY & DRILLS

[NOTES Q21, Q22, Q23]
GEOMETRICAL LOCK PRINCIPLE [NOTES Q21]
$$\text{CI} = [\text{Lower Limit}, \text{Upper Limit}] = \bar{x} \pm \text{ME}$$
⚠️ BOARD TRAP: The sample mean $\bar{x}$ (or sample proportion $\hat{p}$) is GEOMETRICALLY LOCKED AT THE DEAD CENTER of the CI interval. The true population mean $\mu$ is an unobserved constant that may or may not fall inside!
CI = $[1500\text{ hrs}, 1800\text{ hrs}] \implies \text{Center} = \frac{1500+1800}{2} = \mathbf{1650\text{ hrs}} \equiv \mathbf{\bar{x}}$.
TWO-TAILED $z$-CRITICAL
90% Confidence: $z = 1.645$
95% Confidence: $z = 1.960$
98% Confidence: $z = 2.330$
99% Confidence: $z = 2.576 \approx 2.58$
[Q22 Mean CI Drill]:
$\bar{x} = 230.4\text{ V}, \sigma = 15\text{ V}, n = 100, 99\%\text{ CI}$
$\text{ME} = 2.58 \cdot \frac{15}{\sqrt{100}} = 2.58(1.5) = \mathbf{3.87}$
$\mathbf{\text{CI} = 230.4 \pm 3.87\text{ V}}$
[Q23 Proportion CI Drill]:
$18/360 \implies \hat{p} = 0.05, 95\%\text{ CI } (z=1.96)$
$\text{ME} = 1.96 \sqrt{\frac{0.05(0.95)}{360}} = \mathbf{0.0225}$
$\mathbf{\text{CI} = 0.050 \pm 0.0225}$
PART 04

Hypothesis Testing Architecture, Confusion Matrix & Test Selection

🔴 MUST MASTER
HYPOTHESIS DESIGNATION [NOTES Q25]
Null Hypothesis ($H_0$):
Status quo, no effect, equality ($=, \le, \ge$). Assumed true prior to test.
Alternative Hypothesis ($H_a$ or $H_1$):
The claim to be proven ($\ne, >, <$). Determines tail direction!
[Q25 DRILL]: Fiber cable attenuation strictly exceeds $0.20\text{ dB/km}$:
$H_0: \mu = 0.20 \implies \mathbf{H_a: \mu > 0.20}$ (Strictly a Right-Tailed Test).
DECISION RULES: p-VALUE VS. Z-CRIT [NOTES Q26, Q27]
1. $p$-Value Approach:
  • If $p\text{-value} < \alpha \implies$ Reject $H_0$ (Statistically Significant!)
  • If $p\text{-value} \ge \alpha \implies$ Fail to Reject $H_0$
2. Critical Value Approach:
Right tail: If $z_{\text{calc}} > z_{\text{crit}} \implies$ Reject $H_0$.
[Q27 Drill]: $z_{\text{crit}} = 1.645$, $z_{\text{calc}} = 2.10 \implies \mathbf{Reject\ H_0}$.
⚠️ TRAP [NOTES Q26]: $p = 0.002$ does NOT mean "0.2% probability $H_0$ is true". It means there is only a 0.2% chance of observing this extreme data if $H_0$ were true!
WHICH TEST DO I USE? [NOTES Q30, Q31]
DECISION MATRIX:
$\sigma$ Known (any $n$): Z-Test [Q30]
$\sigma$ Unknown, $n \ge 30$: Z-Test (CLT)
$\sigma$ Unknown, $n < 30$: Student's t-test ($df=n-1$)
Compare Means of $\ge 3$ groups: One-Way ANOVA
Categorical Goodness of Fit: Chi-Square ($\chi^2$)
[NOTES Q30 DRILL]: Tiny sample $n=12$, but population $\sigma=5\,\Omega$ is explicitly KNOWN $\implies$ Use Z-test, NOT t-test!

🎯 HYPOTHESIS TESTING CONFUSION MATRIX & POWER ANALYSIS

[NOTES Q28, Q29]
DECISION $H_0$ is TRUE (No Effect) $H_0$ is FALSE (Real Effect)
Reject $H_0$ (Positive) TYPE I ERROR (α)
"False Positive" — Producer's Risk 		CORRECT DECISION
True Positive = POWER ($1 - \beta$)
Fail to Reject $H_0$ (Negative) CORRECT DECISION
True Negative = Confidence ($1 - \alpha$) 		TYPE II ERROR (β)
"False Negative" — Consumer's Risk
[NOTES Q28]: What is a Type I Error?
Mistakenly rejecting a TRUE null hypothesis. You claim a circuit modification works when it actually doesn't (False Alarm / False Positive). Probability $= \alpha$.
[NOTES Q29]: What is Power of the Test?
$$\text{Power} = 1 - \beta$$ The mathematical probability of correctly rejecting a FALSE null hypothesis. Represents the detector sensitivity of the statistical experiment.

Linear Regression, Correlation, Circuit Linearization & Caltech Casio

🟠 HIGH COMPUTATIONAL YIELD
PEARSON r VS. DETERMINATION R² [NOTES Q34, Q35]
Correlation Coefficient ($r$):
-1 ≤ r ≤ +1
Measures strength & direction of linear relationship.
Coefficient of Determination ($R^2 = r^2$):
0 ≤ R² ≤ 1 (or 0% to 100%)
Physical Meaning: The exact proportion/percentage of total variation in $Y$ that is mathematically explained by $X$!
[Q34]: $r = -0.80 \implies R^2 = (-0.80)^2 = \mathbf{0.64 = 64\%}$.
[Q35]: $R^2 = 0.81$ and negative slope $\implies r = -\sqrt{0.81} = \mathbf{-0.90}$ (Strong Negative).
CIRCUIT MODEL LINEARIZATION [NOTES Q36]
Physical capacitor discharge law is non-linear exponential:
$$V(t) = V_0 e^{-t / RC}$$
Apply Natural Logarithm ($\ln$):
$$\ln(V(t)) = \ln(V_0) - \frac{1}{RC} \cdot t$$
Map into Standard Line $Y = A + B X$:
• Plot $Y = \mathbf{\ln(V(t))}$ versus $X = \mathbf{t}$
• $y$-intercept $A = \ln(V_0)$
• Slope $B = -\frac{1}{RC}$

2. Correlation ≠ Causation [Q37]:
Server rack size and cyber-attacks correlate ($r=0.92$). Concluding rack size causes attacks is a fallacy. Lurking variable = Company scale!

PART 06

One-Way ANOVA Table Mathematics, Assumptions & Post-Hoc Tests

🔴 RECONSTRUCTION FAVORITE
FUNDAMENTAL PURPOSE [NOTES Q38, Q39]
Simultaneously tests the equality of POPULATION MEANS across $k \ge 3$ distinct groups:
$H_0: \mu_1 = \mu_2 = \dots = \mu_k$
$H_a: \text{At least one mean is different}$
⚠️ TRAP: ANOVA tests means by comparing variance ratios ($F = \frac{MS_{Tr}}{MSE}$), NOT testing if variances are different.
HOMOSCEDASTICITY ASSUMPTION [NOTES Q40]
Strict Mathematical Definition:
$$\sigma_1^2 = \sigma_2^2 = \dots = \sigma_k^2$$
The population variances across all treatment groups are strictly equal (homogeneous error variance).
Other assumptions: Normality of residuals and independence of observations.
MSE & POST-HOC PROCEDURES [NOTES Q45, Q46]
Mean Square Error (MSE):
Estimates the pooled variance ($\sigma^2$) within separate populations.
Post-Hoc Multiple Comparisons:
ANOVA only tells us "at least one mean differs". To isolate which specific pairs differ, run Post-Hoc Tests (Tukey HSD, Bonferroni, Scheffé).

📊 MASTER ONE-WAY ANOVA TABLE MATHEMATICAL FORMULAS

[NOTES Q41, Q42, Q43, Q44]
Source of Variation Sum of Squares (SS) Degrees of Freedom ($df$) Mean Square ($MS = SS / df$) F-Statistic
Treatment
(Between Groups) 		$$SS_{Tr} = \sum n_i(\bar{x}_i - \bar{\bar{x}})^2$$ $$df_{Tr} = k - 1$$ $$MS_{Tr} = \frac{SS_{Tr}}{df_{Tr}}$$ $$F = \frac{MS_{Tr}}{MSE}$$
Error
(Within Groups) 		$$SSE = SST - SS_{Tr}$$ $$df_E = N - k$$ $$MSE = \frac{SSE}{df_E}$$
Total $$SST = SS_{Tr} + SSE$$ $$df_T = N - 1$$ — —
ADDITIVITY CHECKS:
• $df_{Tr} + df_E = df_T \implies (k-1) + (N-k) = N-1$
• $SS_{Tr} + SSE = SST$
[Q42 DRILL]: RECOVER GROUPS k
$SS_{Tr} = 240, MS_{Tr} = 60$
$df_{Tr} = \frac{SS_{Tr}}{MS_{Tr}} = \frac{240}{60} = 4$
$df_{Tr} = k - 1 = 4 \implies \mathbf{k = 5\text{ groups}}$
[Q43 DRILL]: RECOVER TOTAL SST
$k = 3, N = 15, MS_{Tr} = 50, MSE = 10$
$SS_{Tr} = MS_{Tr} \cdot (k-1) = 50(2) = 100$
$SSE = MSE \cdot (N-k) = 10(12) = 120$
$\mathbf{SST = 100 + 120 = 220}$
PART 07

Design of Experiments (DOE), Factorial Models & Taguchi Robustness

🔴 MODERN ECE CURRICULUM

🛡️ THE HOLY TRINITY OF EXPERIMENTAL DESIGN

[NOTES Q48, Q49, Q50, Q53]
1. RANDOMIZATION [NOTES Q48]
Purpose: Averages out the effects of EXTRANEOUS / UNKNOWN FACTORS (factors you cannot see).
Example: Picking thermal sensors blindly out of a bin rather than test sequence order prevents time-based drifting/temperature lurking bias!
2. BLOCKING [NOTES Q49, Q51, Q52]
Purpose: Controls and isolates the effects of KNOWN NUISANCE FACTORS (factors you can see).
Example: Testing 2 cable jackets equally across 2 different uncalibrated pulling machines ensures machine bias doesn't contaminate jacket tensile strength!
3. REPLICATION [NOTES Q50]
Purpose: Applying treatment across multiple distinct experimental units to estimate purely random experimental error and reduce chance variation.
⚠️ REPETITION TRAP [Q50]: Reading gain 3x on the same circuit on the same scope without resets is strictly REPETITION, NOT true replication!
ANALYZING RCBD ANOVA RESULTS [NOTES Q51, Q52]:
If Machine/Rig Block has $p = 0.001$ (Massive $F_{\text{calc}}$), but Etching Treatment has $p = 0.58$ (Small $F_{\text{calc}}$):
• Conclusion: Blocking was highly effective & necessary (isolated huge machine wear variance). The etching methods themselves have NO statistically significant difference!
2^k FULL FACTORIAL DESIGN & INTERACTIONS [NOTES Q53, Q55, Q56, Q58]
THE FATAL FLAW OF OFAT [Q53]:
The traditional One-Factor-At-A-Time (OFAT) approach CANNOT DETECT INTERACTIONS between engineering variables!
Total Distinct Runs ($2^k$ Factorial) [Q56]:
$$N_{\text{runs}} = 2^k \quad \text{For 3 factors: } 2^3 = \mathbf{8\text{ runs}}$$
Where $k$ = number of factors evaluated at 2 levels each.
Factorial Sum of Squares Formula [Q58]:
$$SS_A = \frac{(\sum A^+ - \sum A^-)^2}{4n}$$
Exam drill: $\sum A^+ = 25+30 = 55$, $\sum A^- = 15+18 = 33$, $n=1$.
$$SS_A = \frac{(55 - 33)^2}{4(1)} = \frac{22^2}{4} = \frac{484}{4} = \mathbf{121.0}$$
GENICHI TAGUCHI ROBUST PARAMETER DESIGN [NOTES Q59, Q60]
Taguchi Philosophy & Orthogonal Arrays (OA):
Maximize robustness (insensitivity to uncontrollable noise factors like temperature fluctuations) at minimal cost. Uses balanced orthogonal matrices (e.g. $L_9, L_8$) providing FEWER RUNS with BALANCED FACTOR LEVELS [Q59].
Objective When to Use ECE Exam Target
Nominal-the-Best Target is fixed value 5.0V Regulator [NOTES Q60]
Smaller-the-Better Want response as small as possible Defects, Bit Error Rate (BER), Noise
Larger-the-Better Want response as large as possible Gain, SNR, Tensile Strength, Lifespan
PART 08

Don't Confuse These — High-Risk Multiple Choice Distinctions

⚠️ FINAL CHECK
ACCURACY VS. PRECISION
• Accuracy: Proximity to True Value. Degraded by systematic offset / probe DC bias.
• Precision: Repeatability / Tightness of cluster. Degraded by random circuit noise ($\sigma^2$).
A fixed +50mV shift leaves PRECISION 100% UNTOUCHED!
RANDOMIZATION VS. BLOCKING
• Randomization: Balances factors you CANNOT SEE (unobserved lurking parameters).
• Blocking: Balances factors you CAN SEE (known machines, operators, test rigs).
REPLICATION VS. REPETITION
• Replication: Re-running on fresh units with full system resets to estimate true error variance.
• Repetition: Measuring the same physical unit 3x in a row without resetting anything.
Z-TEST VS. STUDENT'S T-TEST
• Use Z-test: Whenever population standard deviation $\sigma$ is known (even if $n=12$!), or when $n \ge 30$.
• Use t-test: ONLY when $\sigma$ is unknown AND sample size is small ($n < 30$).
TYPE I (α) VS. TYPE II (β) ERROR
• Type I Error ($\alpha$): False Positive. Rejecting $H_0$ when it's true. (Producer's risk).
• Type II Error ($\beta$): False Negative. Failing to reject a false $H_0$. (Consumer's risk).
• Power: $1 - \beta$ (Probability of detecting real differences).
SKEWNESS DIRECTION RULES
• Direction tracks the LONG TAIL, never the peak!
• Positive (Right) Skew: Tail to the right $\implies \text{Mode} < \text{Median} < \text{Mean}$.
• Negative (Left) Skew: Tail to the left $\implies \text{Mean} < \text{Median} < \text{Mode}$.
