Universal Synthesis Rules

🟠 HIGH-YIELD
SOP \(\to\) 2-Level NAND-NAND

Sum of Products maps directly to 2-level NAND. Minimum NANDs for \(F = AB + CD\) is 3 Gates.

$$\overline{\overline{AB} \cdot \overline{CD}} = AB + CD$$
POS \(\to\) 2-Level NOR-NOR

Grouping 0s in K-map yields Product of Sums (POS), which directly realizes a 2-level NOR-NOR circuit without inverters.

Consensus / Redundancy Theorem
$$AB + A'C + BC = AB + A'C$$
Dual: \((A+B)(A'+C)(B+C) = (A+B)(A'+C)\)
Odd Function: \((A \oplus B) \oplus C = 1\) when an ODD number of inputs are 1.

Static Hazards & Tabular QM

⚠️ COMMON TRAP
Static-1 Hazard Elimination

Occurs in \(F = AB + A'C\) when \(B=C=1\) and \(A\) transitions \(1 \to 0\). Output momentarily drops to \(0\).

Fix: Add consensus term \(BC \implies F = AB + A'C + \mathbf{BC}\)
Quine-McCluskey (QM) Method

Algorithmic tabular technique suited for software/computer minimization when input variables exceed 5 or 6.

EPI: Essential Prime Implicant covers \(\ge 1\) minterm not covered by any other PI.

Half Adder & Full Adder Architecture

HALF ADDER
2 Inputs (\(A, B\)), 2 Outputs:
$$\Sigma = A \oplus B$$
$$C_{out} = A \cdot B$$
FULL ADDER
3 Inputs (\(A, B, C_{in}\)), 2 Outputs:
$$\Sigma = A \oplus B \oplus C_{in}$$
$$C_{out} = AB + C_{in}(A \oplus B)$$
Exam Trap: For Full Adder with \(A=1, B=1, C_{in}=0 \implies \mathbf{\Sigma = 0, C_{out} = 1}\).

Q18–Q38 In-Depth Notes
SR FLIP-FLOP Race at 11
$$Q_{\text{next}} = S + R'Q$$

JK FLIP-FLOP Universal FF
$$Q_{\text{next}} = J Q' + K' Q$$
\(J=K=0 \to\) No change
\(J=K=1 \to\) Toggle (\(Q'\))

$$Q_{\text{next}} = D$$
From JK: Connect \(J=D, K=D'\)
Stores 1 bit reliably on clk edge
T FLIP-FLOP Freq Divider
$$Q_{\text{next}} = T \oplus Q$$
From JK: Connect \(J=K=T\)
When \(T=1 \implies f_{out} = f_{clk}/2\)

FSM Paradigm: Moore vs. Mealy Machines

CORE FSM
MOORE MACHINE
  • • Output depends ONLY on Present State
  • • Output written INSIDE state circle (\(S_n/\text{out}\))
  • • Synchronous output (Glitch-free)
  • • Sequence detection requires \((N+1)\) States
  • • Ex: 2 consecutive coins \(\to\) 3 States (2 FFs)
MEALY MACHINE
  • • Output depends on Present State AND Inputs
  • • Output written on TRANSITION ARCS (\(\text{in}/\text{out}\))
  • • Faster asynchronous response to input
  • • Sequence detection requires \(N\) States
  • • Ex: 2 consecutive coins \(\to\) 2 States (1 FF)

Ripple vs. Synchronous

Delay Mechanics
Ripple (Asynch): Clock ripples stage-by-stage. Delay \(= N \times t_{pd}\). (Slow).
Synchronous: All FFs share common clock. Delay \(= t_{pd}\) (single stage).

8085 Core Registers & Buses

HARDWARE
  • Program Counter (PC): 16-bit register holding the address of the NEXT instruction to be fetched.
  • Stack Pointer (SP): 16-bit register pointing to the top address of the LIFO stack.
  • Address Bus: 16-bit, UNIDIRECTIONAL (CPU \(\longrightarrow\) Memory/IO).
  • Data Bus: 8-bit, BIDIRECTIONAL (CPU \(\longleftrightarrow\) Memory/IO).
READY Pin: Active-HIGH input from slow memory/IO to insert CPU WAIT states.

Hardware Protection & IO Rules

INTERFACING
  • Flyback Diode: Connected in reverse-parallel across inductive loads to suppress back-EMF (\(E = -L \frac{di}{dt}\)).
  • Pull-Up / Down Resistors: Prevents floating high-impedance inputs from picking up EMI/noise.
  • 8051 Reset Pin State: Immediately after hard reset, all port pins default to Logic HIGH (\(+5\text{V} / \text{FFH}\)).
DMA Controller: Performs direct memory-to-peripheral transfers without CPU overhead.

🚫 DON'T CONFUSE THESE (CRITICAL BOARD EXAM TRAPS)

High-yield distinctions frequently tested in multiple-choice exams

PROGRAM COUNTER vs. STACK POINTER
PC (Program Counter): Holds the 16-bit address of the NEXT instruction to fetch. Increments automatically.
SP (Stack Pointer): Holds the 16-bit address of the TOP of the LIFO stack. Modified by PUSH, POP, CALL, RET.
⚠️ TRAP: Never confuse PC with instruction register or accumulator.
HARVARD vs. VON NEUMANN
Harvard: Separate buses & memories for Code and Data. Allows simultaneous fetch & access \(\to\) Higher Throughput.
Von Neumann: Shared bus and shared memory for Code and Data \(\to\) Von Neumann bottleneck.
⚠️ TRAP: Harvard does NOT eliminate the ALU or require non-volatile RAM.
SRAM vs. DRAM
SRAM: 6T Flip-Flop cell. Fast, costly, DOES NOT NEED REFRESH. Used in Cache.
DRAM: 1T + 1 Capacitor cell. Dense, cheaper, REQUIRES PERIODIC REFRESH. Used in main RAM.
⚠️ TRAP: DRAM loses charge due to capacitor leakage even with power ON.
RIPPLE vs. SYNCHRONOUS COUNTERS
Ripple (Asynchronous): FF \(Q\)-output clocks next stage. Delays accumulate: \(t_{tot} = N \cdot t_{pd}\).
Synchronous: Clock pin of every FF connected in parallel to common clock. Negligible cumulative delay.
⚠️ TRAP: Both can be built with JK or D flip-flops; clock wiring is the key.
ECL vs. CMOS
ECL: Fastest logic family (\(2\text{ ns}\) delay), non-saturating BJTs, highest power consumption (\(25\text{ mW}\)).
CMOS: Lowest static power consumption (\(0.1\text{ mW}\)), highest noise immunity (\(3.0\text{ V}\)), best for EMI.
⚠️ TRAP: Standard TTL has higher noise immunity than ECL, but CMOS has the highest.
ADDRESS BUS vs. DATA BUS
Address Bus: 16-bit, UNIDIRECTIONAL outward from CPU to Memory/IO decoder.
Data Bus: 8-bit, BIDIRECTIONAL between CPU and Memory/IO.
⚠️ TRAP: Control bus contains individual control lines, but Address is strictly 1-way.
