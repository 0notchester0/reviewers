TRANSMISSION MODES
  • • Simplex: 1-way strictly (MRT-3 displays, FM Radio, TV Broadcast)

  • • Mesh: Point-to-point dedicated links; $L = \frac{N(N-1)}{2}$; $O(N^2)$ cables

PAN → LAN → MAN → WAN → GAN
  • • PAN: Bluetooth headset to mobile phone
  • • LAN: Office or school building (Ethernet 802.3)
  • • MAN: City-wide optical metropolitan loop
  • • WAN: Worldwide inter-network (The Internet)
  • • GAN: Global satellite constellations (Starlink)

ASYNCHRONOUS MODE 20-30% OVERHEAD

Frames characters byte-by-byte using Start bit (logic 0) and Stop bit (logic 1). Transmitter & receiver clocks run independently.

• Used in low-speed serial (RS-232, POS scanners)
• ⚠️ Huge overhead penalty for large datasets!
SYNCHRONOUS MODE HIGH EFFICIENCY

Transmits large continuous blocks framed with preamble/synch flags. Shared clock signal or line-coding PLL synchronizes receiver.

🔴 Failure Trap [NOTES: Q18]: If sender & receiver clocks drift out of phase, an entire block of data is corrupted.
ISOCHRONOUS MODE ZERO JITTER

Data is strictly guaranteed to arrive at exact, fixed time intervals without variable delay or buffer fluctuation.

🟠 Board Exam App [NOTES: Q19, Q20]: Critical for BPO VoIP softphones & real-time live video streams to eliminate stuttering.

2-WIRE VS 4-WIRE INTERFACING [NOTES: Q13, Q14]

🔴 HIGH PROBABILITY

2-Wire Circuits: Carries both Tx and Rx on a single pair of wires. Standard for the local subscriber loop (PSTN telephone line) to save physical copper infrastructure cost.

4-Wire Circuits: Separates Tx (2 wires) and Rx (2 wires). Used in carrier trunks, toll lines, and long-distance digital facilities. Key advantage: Allows true full-duplex simultaneous transmission without collision.

⚡ THE HYBRID CIRCUIT (HYBRID COIL)
• Converts bidirectional 2-wire local loops ↔ separate 4-wire Tx/Rx circuits.
• Operates on balanced transformer bridge principle.
⚠️ BOARD EXAM TRAP: Impedance mismatch across the hybrid coil reflects energy back to the talker → produces talker/listener echo, necessitating Echo Suppressors or Echo Cancellers.

SWITCHING PARADIGMS: PACKET VS CIRCUIT [NOTES: Q22]

🔵 CORE ARCHITECTURE
Attribute Circuit-Switched (PSTN) Packet-Switched (Internet)
Dedicated Path Yes (Setup → Hold → Teardown) No (Dynamic per-packet routing)
Bandwidth Use Wasted when silent High efficiency (Statistical multiplexing)

Primary advantage: Packet switching allows far more efficient utilization of overall network bandwidth across shared transmission lines.

FORMULA 01
TRANSMISSION DELAY ($t_{\text{tx}}$)
$$t_{\text{tx}} = \frac{L}{R} = \frac{\text{Bytes} \times 8}{R_{\text{bps}}}$$
• $L$: Packet length in bits ($1\text{ Byte} = 8\text{ bits}$)
• $R$: Physical channel data rate in bits/s
• USE: Time to push bits onto physical wire.
⚠️ TRAP: Always convert payload Bytes to bits! ($1500\text{ Bytes} = 12,000\text{ bits}$).
FORMULA 02
ASYNC CHARACTER EFFICIENCY
$$\eta = \frac{D}{D + P + S_{\text{start}} + S_{\text{stop}}} \times 100\%$$
• $D$: Data payload bits (typically 7 or 8)
• $P$: Parity bits (0 or 1)
• Total Frame $= D + P + \text{Start} + \text{Stop}$
📌 STANDARD CASES:
8-N-1: $8/10 = 80.0\%$
8-E-1: $8/11 = 72.7\%$ [NOTES: Q21]
FORMULA 03
TOKEN RING MAX LATENCY
$$t_{\text{wait, max}} = (N - 1) \times T_{\text{holding}}$$
• $N$: Total number of stations on ring
• $T_{\text{holding}}$: Max token transmit hold limit
• Assumes all other $N - 1$ stations seize token
📌 50 Stations @ $10\,\mu\text{s}$ [NOTES: Q9]:
$$t_{\text{wait}} = (50 - 1) \times 10\,\mu\text{s} = \mathbf{490\,\mu\text{s}}$$

ARCHITECTURAL GROUPING OF THE 7 LAYERS [NOTES: Q52]
LAYERS 5, 6, 7 (APPLICATION SUPPORT LAYERS)
🔴 Board Exam Question 52: Responsible for allowing interoperability among unrelated software systems across heterogeneous operating environments.
LAYER 4 (TRANSPORT BOUNDARY)
The true boundary layer: completely isolates user application software layers from the physical subnet hardware beneath.
LAYERS 1, 2, 3 (MEDIA / SUBNET LAYERS)
Responsible for the physical, electrical, link-level, and routing movement of raw data from one geographic point to another.
DATA ENCAPSULATION FLOW [NOTES: Q46]
L7-L5: Application Payload Stream Data
↓ L4: [L4 Header: Src/Dst Ports + Seq] + Payload Segment
↓ L3: [L3 Header: Src/Dst IP] + Segment Packet
↓ L2: [L2 Header: MACs] + Packet + [FCS Trailer / CRC] Frame
↓ L1: Pulsed Light / Voltages / Radio Waves Bits
🔴 Key Rule [Q46]: As data travels DOWN the stack at Tx, each layer appends its own specific Protocol Control Information (Header/Trailer). At Rx, each layer strips its corresponding header.
REPEATER / HUB
OSI LAYER 1 (PHYSICAL)
  • • Regenerates & amplifies electrical/optical signals [Q25]
  • • Dumb broadcast: mirrors input on port 1 out to ALL other ports
  • • Cannot read MAC or IP addresses
  • • 1 single Collision Domain; 1 Broadcast Domain
BRIDGE / SWITCH
OSI LAYER 2 (DATA LINK)
  • • Forwards frames based on MAC addresses [Q23, Q54]
  • • Filters traffic between LAN segments [Q26, Q27]
  • • Micro-segments network: Isolates collision domains (each port is 1 collision domain)
  • • Still belongs to 1 single Broadcast Domain (unless VLANs)
ROUTER
OSI LAYER 3 (NETWORK)
  • • Connects distinct logical subnets and WANs together [Q24, Q29]
  • • Forwards packets based on IP addresses
  • • Path selection / dynamic routing (OSPF, BGP)
  • • Isolates broadcast domains (blocks broadcasts from propagating)
GATEWAY
OSI LAYERS 4–7 (UPPER)
  • • Universal protocol converter [Q28]
  • • Translates between incompatible network architectures (e.g., TCP/IP to IBM SNA mainframe)
  • • Modifies packet payloads, encodings, and command sets across architectures

ERROR DETECTION, CHANNEL CODING & COMPUTATIONAL WORKED PROBLEMS

PAGE 4
THE THREE ERROR CONTROL PILLARS
🔴 REDUNDANCY IS THE FOUNDATIONAL PRINCIPLE [Q36]
1. PARITY CHECK [Q37]

Appends 1 extra bit so total count of 1s is consistently even or odd.

🔴 Strict Rule: Detects ONLY an ODD number of bit errors (1, 3, 5). Completely fails if 2 bits flip simultaneously!
2. CHECKSUM [Q48]

1's or 2's complement summation of 16-bit payload words. Placed in header.

Used primarily at the Transport Layer (TCP/UDP) and IP Layer. Very light computational overhead for software implementations.
3. CRC (POLYNOMIAL) [Q35]

Modulo-2 binary division using Linear Feedback Shift Registers (LFSR).

🔴 Major Strength: Outstanding ability to detect burst errors (corrupted bit sequences in physical lines).
⚙️ CRC GENERATOR MATHEMATICAL ENGINE [NOTES: Q32]
MATHEMATICAL RULES:
• Given a Generator Polynomial Divisor $G(x)$ of length $K$ bits:
1. Degree of Divisor Polynomial: $n = K - 1$
2. Zeros appended to original data payload: $n\text{ zeros}$ ($K - 1\text{ zeros}$)
3. Width of FCS Remainder: $n\text{ bits}$ ($K - 1\text{ bits}$)
BOARD EXAM CASE (Q32):
Generator polynomial length = 6 bits (e.g., $110101_2$, degree $n = 5$):
• Data dividend appended with exactly 5 zeros.
• Remainder (FCS) produced has width of exactly 5 bits.
Transmitted stream $= [\text{Data Payload}] + [5\text{-bit FCS Remainder}]$.

STEP-BY-STEP WORKED BOARD EXAM PROBLEMS [Q30, Q31, Q33, Q34]

PROB 1: 10Base-T TRANSMISSION DELAY [Q30] ETHERNET
GIVEN: Payload = 1500 Bytes, Data rate $R = 10\text{ Mbps} = 10 \times 10^6\text{ bps}$.
Step 1: Convert Bytes to bits:
$$L = 1500\text{ Bytes} \times 8\text{ bits/Byte} = 12,000\text{ bits}$$
Step 2: Compute packet emission latency:
$$t_{\text{tx}} = \frac{L}{R} = \frac{12,000\text{ bits}}{10 \times 10^6\text{ bps}} = 0.0012\text{ s} = \mathbf{1.2\text{ ms}}$$
CORRECT ANSWER: 1.2 ms
PROB 2: ASYNC WASTED OVERHEAD [Q31] SERIAL UART
GIVEN: 1,000 characters (8-bit ASCII). Framing: 1 start bit, 1 stop bit, 1 parity bit per char.
Step 1: Identify wasted framing overhead per character:
$$\text{Overhead/char} = 1\text{ start} + 1\text{ stop} + 1\text{ parity} = 3\text{ bits}$$
Step 2: Multiply by total characters:
$$\text{Total Wasted Bits} = 1,000\text{ chars} \times 3\text{ bits/char} = \mathbf{3,000\text{ bits}}$$
CORRECT ANSWER: 3,000 bits
PROB 3: EVEN PARITY GENERATION [Q33] ERROR CODING
GIVEN: 7-bit ASCII payload = 1001011. Scheme = Even Parity.
Step 1: Count the number of '1' bits in original payload:
$$\text{Payload } 1001011 \implies \text{Four (4) '1's}$$
Step 2: Determine required parity bit for even sum:
Since 4 is already an even number, appended parity bit $= \mathbf{0}$.
Total number of 1s in final transmitted 8-bit frame $= \mathbf{4\text{ ones}}$.
ANSWER: Parity Bit = 0; Total 1s = 4
PROB 4: EXPECTED ERRORS FROM BER [Q34] BIT ERROR RATE
GIVEN: 8 packets, each 512 Bytes. System $\text{BER} = 2 \times 10^{-4}$.
Step 1: Calculate total transmitted bits ($N_{\text{bits}}$):
$$N_{\text{bits}} = 8 \times 512\text{ Bytes} \times 8\text{ bits/Byte} = 32,768\text{ bits}$$
Step 2: Compute expected bit errors:
$$\text{Errors} = N_{\text{bits}} \times \text{BER} = 32,768 \times (2 \times 10^{-4}) = \mathbf{6.5536 \approx 6.55}$$
CORRECT ANSWER: 6.55 errors
HAMMING CODE SEC-DED [NOTES: Q49]: Provides Single-Error Correction and Double-Error Detection.
Redundant bit rule: $2^r \ge m + r + 1$ | Parity bit positions: Powers of 2 ($1, 2, 4, 8, 16\dots$)

FDM BANDWIDTH CALCULATION [NOTES: Q71] GUARD BANDS
GIVEN: 10 voice channels, each $B_c = 4\text{ kHz}$. Guard band $B_g = 500\text{ Hz} = 0.5\text{ kHz}$.
Rule: $N$ multiplexed channels require exactly $N - 1$ guard bands:
$$N_{\text{guard}} = 10 - 1 = 9\text{ guard bands}$$
Compute Aggregate Bandwidth:
$$B_{\text{total}} = (N \times B_c) + ((N - 1) \times B_g)$$ $$B_{\text{total}} = (10 \times 4\text{ kHz}) + (9 \times 0.5\text{ kHz}) = 40 + 4.5 = \mathbf{44.5\text{ kHz}}$$
CORRECT ANSWER: 44.5 kHz
TDM AGGREGATE BIT RATE [NOTES: Q70] FRAME EFFICIENCY
GIVEN: 6 digital voice channels @ $128\text{ kbps}$ each. Frame efficiency $\eta = 80\% = 0.80$.
Step 1: Calculate net useful payload bit rate:
$$R_{\text{payload}} = 6 \times 128\text{ kbps} = 768\text{ kbps}$$
Step 2: Solve for total gross link transmission rate:
$$\eta = \frac{R_{\text{payload}}}{R_{\text{aggregate}}} \implies R_{\text{aggregate}} = \frac{768\text{ kbps}}{0.80} = \mathbf{960\text{ kbps}}$$
CORRECT ANSWER: 960 kbps

TCP VS UDP [Q41, Q44, Q47]
TCP: Connection-oriented (3-way SYN handshake), guaranteed sequencing, ACK, retransmission. Used for PDF downloads, Web, Email.
UDP: Connectionless, "fire-and-forget", low overhead (8 bytes), NO retransmission. Used for VoIP, Mobile Legends to eliminate latency.
SWITCH (L2) VS ROUTER (L3) [Q23, Q24]
Switch (Layer 2): Forwards Frames by MAC address. Isolates Collision Domains. Shares 1 Broadcast Domain.
Router (Layer 3): Forwards Packets by IP address. Isolates Broadcast Domains. Connects different subnets.
SYNC TDM VS ASYNC/STAT TDM [Q69]
Synchronous TDM: Fixed dedicated time slot per channel. Slot sent empty if channel idle. Zero jitter. Ideal for uncompressed voice/PCM.
Statistical TDM: Dynamically assigns slots on demand. Carries address header. High efficiency for bursty data networks.

🔴 TOP 5 MUST-MEMORIZE FACTS:
  • 1. Full Mesh link formula: $L = N(N - 1) / 2$. Number of links grows quadratically ($O(N^2)$).
  • 2. Minimum Ethernet frame size: Strictly 64 Bytes. Frames smaller than 64B are runt collision fragments.
  • 3. ISDN BRI channel breakdown: 2 B channels (64k each) + 1 D channel (16k) $= 144\text{ kbps}$ net, $192\text{ kbps}$ gross.
  • 4. Synchronous clock drift: A phase shift corrupts an entire data block (not just 1 character).
  • 5. Parity check detection: Strictly detects only an odd number of bit flips.
🟠 TOP 5 HIGH-YIELD CONCEPTS:
  • 1. Layer 2 vs Layer 3: Switches forward frames by MAC; Routers forward packets by IP and isolate broadcast domains.
  • 2. Hybrid circuit: Connects 2-wire bidirectional local loop to 4-wire separate Tx/Rx trunks; causes impedance reflection echo.
  • 3. Why UDP for VoIP/Gaming: Much lower header overhead (8B vs 20B) and strictly no retransmission lag.
  • 4. FDM Guard Bands: $N - 1$ guard bands are required between $N$ adjacent frequency channels.
  • 5. CRC Divisor degree: A generator polynomial of $K$ bits has degree $n = K - 1$, appends $K - 1$ zeros, and yields an FCS of $K - 1$ bits.
